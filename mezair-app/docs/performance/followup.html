The ten follow-ups

Each item names its implementation and the evidence used to check it.

  1. 01

    Native startup and memory Verified

    Three isolated cold launches per platform, welcome-screen readiness, 15-second idle working set, and a complete 30-minute synthetic streaming soak. Whole-process-tree samples and explicit device budgets are retained.

    Native evidence below

  2. 02

    Window long histories Verified

    Variable-height virtualization above 80 turns; stable turn keys, selection/focus pins, loaded-conversation search, surface/request reveal, saved anchors and disclosure ownership. The 1,000-turn fixture retains fewer than 30 rows.

    717 DOM elements; cold mount and prepend checks

  3. 03

    Stable streaming Markdown Verified

    Settled top-level blocks retain their DOM. The final two nodes stay mutable to preserve partial-list semantics. Reference/footnote definitions use the full-document parser. Character-prefix tests cover tables, lists and unfinished fences.

    Long-code Markdown P95: 1.9 ms

  4. 04

    Off-thread highlighting Verified

    One module worker, one running job, at most 32 requests, cancellation, deduplicated grammar loads, 15-second timeout, 60-second idle disposal, and a 4 MB result cache. Obsolete consumers receive safe plain text.

    Real browser and packaged Electron worker checks

  5. 05

    Bounded data reads Verified

    History pages default to 200 messages with a stable snapshot cursor. Full-history forks still load all ancestors. Factory pages default to 50 runs; SQLite computes local rail counts without hydrating receipts. Hosted pages keep recipient encryption and current access checks.

    32,000-message / 5,000-run service benchmark

  6. 06

    Separate chat subscriptions Verified

    Composer commands, model preferences, artifacts and execution state have separate memoized channels. Composer/rails stay memoized, and activity ignores token-only changes. Unrelated consumers remain idle between real state transitions.

    Zero extra renders across 60 background updates

  7. 07

    Shared dashboard reads Verified

    Main-process single-flight reads across modules/windows; four shared source permits; bounded caches (128 entries and 4 MB per source family). Scope keys, explicit refresh and stale-success fallback remain intact for retained cache entries; eviction releases old rows.

    Cross-window, workspace, refresh and invalidation tests

  8. 08

    Intent warming Verified

    Terminal, palette and later setup steps share their actual lazy import with hover/focus warming. Hidden/save-data requests skip warming. Terminal recovery precedes default shell creation; failed chunks stay contained.

    Real module import readiness measurements below

  9. 09

    Rich owner cleanup Verified

    Folded previews release their bodies; stale comment reads cannot repopulate a closed owner. Tests exercise document/sketch frames, blob URLs, observers, large diffs, images, Mermaid, actual pop-outs and software WebGL contexts.

    30 preview cycles, 12 rich cycles, 5 pop-outs, 3 released GL contexts

  10. 10

    CI performance budgets Verified

    OS-pinned Ubuntu 24.04 and Windows 2022 jobs use an immutable reference, paired renderer samples and raw artifacts. Gates cover bundle growth, heap, DOM, streamed P95 and native memory/startup.

    Paired renderer and both native gates pass

Verification and guardrails

Desktop: 3,453 tests passed, 12 skipped; renderer/main typechecks, lint and production build pass. All 19 hosted factory tests pass, including cursor ties, page bounds, recipient-only snapshots and membership revocation. The backend typecheck passes.

Browser checks cover cold mount, selection/focus retention, disclosure restoration, prepend anchors, loaded search, pinned scrolling, dashboard races, Markdown semantics, real worker output, zero unrelated channel renders and rich-owner cleanup. The settings-editor probe uses production state channels; it is not a full Settings-route end-to-end test. Software WebGL checks verify context release, rather than native GPU memory.

Follow-up on 4 November: all 508 backend tests pass. The enrollment fixture now clears the shared test Durable Object's prior cooldown timestamp before using its independent fake clock. Attempts within each fixture still exercise the real provider throttle and device-cap enforcement. Production authentication and rate limits are unchanged. No provider execution, publication or production deployment was performed.

CI budgets and reproducibility

The Ubuntu job builds the immutable reference and candidate, records static closures, alternates five renderer pairs in one browser, and retains the raw JSON. Gates allow at most 2% bundle growth, 10% retained-heap growth and 15% streamed-P95 or mount growth; the 1,000-turn DOM must stay below 2,000 elements and scroll geometry below 30 reads per burst. The Windows 2022 job packages both revisions and captures three cold launches plus the candidate’s 30-minute soak.

Node is pinned to 22.16.0 in CI; Electron comes from the frozen lockfile. Hosted OS images and the installed Chrome patch can change; the actual versions are captured in each artifact, and each comparison uses one runner/browser. Update the immutable reference deliberately when adopting new budgets.
